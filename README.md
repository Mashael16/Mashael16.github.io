# Mashael Alharbi — Portfolio

A responsive, static 4-page portfolio. No build tools or backend are needed.

## Open and publish

Open `index.html` in a browser, or upload this folder to GitHub Pages, Netlify, or any static host. The `projects` folder contains independently shareable project case studies.

## Replace before publishing

- Add your LinkedIn URL and contact email in the navigation/contact area once you have decided which to publish.
- Add your CV download link, if desired.
- Replace decorative project illustrations with your own real screenshots. The illustrations are deliberately conceptual and are not screenshots of the products. Suggested screenshot filenames from your notes: `dashboard.png`, `branch-not-ready.png`, `branch-ready.png`, and `masar-01-home.png` through `masar-04-404.png`.
- Confirm the official name of the Tuwaiq Academy bootcamp in the About section.
- Review the skill list before publishing so it reflects what you want to discuss in an interview.
